# Migrato

Учебный правовой путеводитель для иностранцев в Казахстане. Интерфейс на русском, казахском и английском языках: маршрут адаптации, ситуационный тест, симуляция, календарь, справочник организаций и практические инструменты. Консультант Барыс сопровождает действия пользователя.

## Запуск

Нужен Node.js с поддержкой встроенного тестового раннера. Сторонних npm-зависимостей нет.

```sh
npm start
```

Откройте `http://127.0.0.1:4173/`.

```sh
npm test
npm run build
```

Команда сборки создаёт автономный `Migrato.html`. Он не включается в Git; исходники находятся в `dist/`, проверки — в `tests/`.

## Netlify

В настройках публикации используйте корень репозитория и папку `dist`. Конфигурация и HTTP-заголовки заданы в `netlify.toml`; отдельная команда сборки не требуется.

## Данные и источники

Приложение работает в браузере и сохраняет прогресс локально. Серверная часть, сбор настоящих документов и внешние AI-вызовы отсутствуют. Правовые материалы содержат ссылки и границы проверки; календарь не вычисляет неподтверждённые юридические сроки. Учебные отметки не подтверждают подачу или одобрение документов.

Локальная папка `final/` содержит окончательное ТЗ из восьми частей, журнал Ии2, паспорт проекта, архивы скриншотов и исходников, а также инструкцию. Документы описывают v20 и отдельно указывают незавершённые внешние проверки. Этот комплект хранится отдельно от публичного репозитория и исключён через `.gitignore`.
